## Academic Project

### E-EYE: Multi-Modal Refractive Error Estimation Using Short-Sequence Eccentric Photorefraction

**Project Area:** Computer Vision, Machine Learning, Artificial Intelligence, and Multimodal Data

E-EYE is an academic project that explores the use of computer vision and machine learning for refractive error estimation.

The project combines image-based information with additional measurements to investigate how technology can support more accessible and affordable eye screening solutions.

My contribution focuses on medical protocols and the organization of medical-related procedures and requirements. This experience helped me understand the importance of combining technical development with proper planning, teamwork, responsible practices, and user-centered design.

### Technologies and Methods

- Python
- OpenCV
- Computer Vision
- Image Processing
- Deep Learning
