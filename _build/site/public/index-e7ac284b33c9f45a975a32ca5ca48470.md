## Featured Project



### E-EYE: Multi-Modal Refractive Error Estimation



**Project Category:** Data Science, Artificial Intelligence, and Computer Vision



E-EYE is an academic project that explores how computer vision and machine learning can support refractive error estimation and accessible eye screening.



The project combines image-based information with additional measurements to investigate how technology can support affordable screening solutions.
