# \## Featured Project

# 

# \# E-EYE

# 

# \### Multi-Modal Refractive Error Estimation Using Short-Sequence Eccentric Photorefraction

# 

# \*\*Project Category:\*\* Data Science, Artificial Intelligence, and Computer Vision

# 

# E-EYE is an academic project that explores how computer vision and machine learning can support refractive error estimation and accessible eye screening.

# 

# The project combines image-based information with additional measurements to investigate how technology can assist in developing affordable screening solutions.

# 

# \### Project Objectives

# 

# \- Explore computer vision techniques for eye-related image analysis.

# \- Process image information using OpenCV.

# \- Investigate machine learning approaches for refractive error estimation.

# \- Combine visual information with additional measurements.

# \- Develop a technology-based solution for possible use in accessible screening environments.

# 

# \### Technologies and Methods

#

# \- OpenCV

# \- Computer Vision

# \- Image Processing
